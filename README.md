# 博客园 · 第三方 Android 原生客户端

Kotlin + Jetpack Compose，版本 **1.5.0**（versionCode 6），最低 Android 8.0（API 26），包名 `dev.garden.reader`。本应用不是博客园官方客户端，与博客园官方无关联；名称和标志不代表官方认证。

## 1.5.0 更新

当前主分支另包含尚未新建 Release 的作者主页与官方博文评论改进，见 [作者主页验收](AUTHOR_PROFILE.md) 和 [官方评论接口记录](COMMENTS_API.md)。博文评论现只走官方 API，正文底部有原生评论预览；新闻维持既有读取逻辑。

- 点击博文作者头像进入原生作者页，浏览作者公开博文并打开正文；不明来源或非博客作者不拼接猜测主页。
- 首页、新闻、收藏统一独立搜索页。顶部原生搜索输入框与胶囊范围栏；收藏只搜索本机已收藏的文章和新闻，支持全部、文章、新闻筛选，不需要登录。
- 首页分类改为带移动选中底片的一体胶囊栏。上滑收起首页顶栏，下滑平滑恢复，状态栏顶部模糊保留。
- 正文移除右侧目录浮条，底栏改为明确的列表目录图标；评论改为全屏原生列表卡片。
- 1.5.0 发布版曾优先读取网页评论；当前主分支的博文评论已改为仅使用官方 API，需合法授权，不回退网页爬取。
- 「我的 → 阅读时间」新增 26 周热力图、7/30/90 天及全部统计、今日/累计时长、阅读篇数与天数。仅统计加载完成的正文在前台可见时的本机停留；后台、锁屏、覆盖页面及加载中不计入。异常长采样间隔会丢弃，不补造历史数据；不判断人的实际注意力。
- 原生代码块新增语言栏、行号、轻量语法高亮、复制及系统文件选择器保存，配色随主题；长代码仅预览前 500 行或 40000 字，复制与保存保留完整内容。
- 缺失或加载失败的头像统一使用默认人像，不再使用首字母。

阅读统计只保存在当前设备，唯一文章记录只存 URL 的 SHA-256 摘要，不上传云端。换机/卸载不会自动恢复历史。使用测试数据的演示热力图预览会单独标注，不是用户历史。

## 功能

- 首页：最新、48 小时阅读排行、10 天推荐排行、精华、知识库；独立新闻及本地收藏。
- 列表、正文直接提取博客园网页版，不使用 RSS。Compose 原生显示标题、段落、代码、引用、图片和文本表格；无 WebView，不执行网页脚本。
- 首页搜索博文、新闻页搜索新闻、收藏页搜索本机收藏。前两者调用官方站内搜索 API，需要有效授权和接口权限，不用当前列表冒充全站结果。
- 博文及新闻的原生评论面板，支持分页读取与发布；未提供接口的文章类型明确提示不支持。
- 网页原版矢量统计图标，按评论、点赞、阅读显示。未提供的数字显示「—」；展示点赞数不代表支持点赞提交。
- 玻璃悬浮底栏、卡片、目录、原生授权、评论及分组设置；Android 12 起真实背景采样模糊，旧系统半透明降级。
- 深浅色与跟随系统主题、Android 12+ 莫奈取色、透明状态栏与手势区；交互控件避让系统手势。
- 文章横向进入/退出、预测性返回跟手及取消回弹；遵循系统动画设置。启动器、系统启动屏、应用启动动画使用矢量官网标志，避免低清位图放大。
- 「我的」包含账号资料、通用、外观、阅读、阅读时间、新文章通知、检查更新及关于。

## 安装与更新

[GitHub Releases](https://github.com/kotuyako/cnblogs/releases) 提供 APK。当前交付是 **debug 签名体验包**，不是商店正式发行包。同签名版本可覆盖安装并保留本机数据。请勿为解决签名错误而盲目卸载，否则会丢失本地数据。

「我的 → 检查更新」查询此仓库最新正式 Release，按数字比较版本。网络失败、限流、仓库无正式版本会显示错误，不误报「已是最新版」。发现更新后由用户打开发布页，不静默下载安装。

## 原生授权与隐私

应用不收集账号密码。在博客园官方账号中心 `https://account.cnblogs.com/tokens` 创建 PAT 后，粘贴到原生授权页。创建令牌本身需要账号中心，应用不嵌入该网页。

仅向 `https://api.cnblogs.com` 发送 Bearer 及 `Authorization-Type: pat`，关闭重定向；通过 `/api/users/v2` 验证身份，必要时通过 `/api/users` 补充资料。令牌由 Android Keystore AES-GCM 加密保存在本机，不写日志、源码、预览或 GitHub；授权页禁止系统截图与最近任务快照。退出清除本机令牌。

资料页包含昵称、头像、园号、入园时间、园豆、会员及园龄。**接口没有返回的值显示「官方接口暂未提供」**，不使用参考图的用户数据、不推算注册日期、不将 API 授权视为 VIP。

公开正文失败时可尝试官方授权正文接口；授权正文只存当前内存，不写磁盘。PAT 不等于网站会员会话，不保证能读取受限内容。账号身份有效也不代表每个 API 都有权限。

## 评论与搜索

博文评论：`/api/blogs/{blogApp}/posts/{postId}/comments`；新闻评论：`/api/news/{newsId}/comments`。输入点击发布后会以你的账号公开发送，发送中禁用重复提交；不自动重试。网络中断时应先刷新确认，避免重复发布。

当前主分支博文评论仅使用官方 API，按每页 10 条读取。首次失败不会显示暂无评论，重试保留失败页码；发布成功自动刷新，结果不确定时保留草稿并要求先刷新核对。新闻维持既有读取流程。

站内搜索：`/api/ZzkDocuments/Blog`、`/api/ZzkDocuments/News`、`/api/ZzkDocuments/Kb`。全站搜索及评论发布需要相应 API 权限，401/403 会明确显示；本机收藏搜索无需授权。不会绕过网站人机验证，不会回退成网页 UI。接口说明见 [博客园 Open API 文档](https://api.cnblogs.com/help)。

## 新文章通知

默认关闭，在「我的 → 新文章通知」手动开启。Android 13+ 需要通知权限。使用系统 JobScheduler 约每 15 分钟检查公开首页，首次只建立基线、不通知历史文章，后续合并通知，点击原生打开正文。

这是 **本机定时轮询通知，不是即时服务器推送**。省电、后台限制、网络与系统调度可能延迟检查；关闭开关取消任务。没有接入第三方推送 SDK，不采集推送设备标识。

## 构建

Android Studio 打开本目录，安装 SDK Platform 35 / Build Tools 35.0.0，JDK 17 或 21。

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`。依赖固定：AGP 8.9.2、Gradle 8.11.1、Kotlin 2.1.21、Compose BOM 2025.06.01、Lifecycle 2.9.1、Jsoup 1.18.3。首次同步需访问 Google Maven 和 Maven Central。

源码不包含 PAT、GitHub 登录凭据、签名私钥、用户数据、缓存、构建目录或本地 SDK 配置。不同机器默认 debug 密钥不同，重新构建的 APK 不保证能覆盖现有安装；长期发布应管理稳定发行密钥，**不要把私钥上传公开仓库**。

## 测试与限制

逻辑测试覆盖网页解析、分页、图片/头像、安全 URL、原生正文、授权、评论目标及版本比较。Android Studio 预览见 `ui/DesignPreviews.kt`；原生组件渲染预览不等于手机实机截图。

不使用真实账号凭据的自动测试不会公开发评论，也不能证明账号所有接口可用。头像、通知时效、手机玻璃效果、返回手势流畅度仍需实机验收。网页结构与接口规则变化可能导致读取失败。

收藏与偏好保存在本机；已读取公开正文缓存，收藏本身不自动下载全文。图片为有界内存缓存，不保证离线可用。复杂公式、嵌入视频、交互网页不执行，表格按可横向滚动文本呈现。
